# Library2 — Система управления личной библиотекой

Консольное Java-приложение для каталогизации, поиска и анализа личной библиотеки с интеграцией Google Books API. Позволяет вести учет книг в едином интерфейсе независимо от формата: бумажные, электронные, аудиокниги.

## Проблема

У большинства книголюбов и исследователей учет библиотеки ведется несистемно. Бумажные книги записаны в одном месте, электронные лежат в папках на компьютере, аудиокниги часто вообще не учитываются. Поиск нужной книги занимает от 5 до 15 минут. Около 25% купленных книг теряются из виду и остаются непрочитанными, а 15% покупаются повторно из-за отсутствия единого каталога. Добавление одной книги вручную занимает 3-5 минут, а обновление записей происходит 1-2 раза в месяц, что приводит к неактуальности данных.

Отсутствие системы напоминаний приводит к тому, что начатые книги забываются и остаются незавершенными. Невозможно проанализировать свои читательские предпочтения: какие жанры преобладают, сколько книг прочитано за год, какие авторы выбираются чаще всего.

## Обзор аналогов

Существующие решения либо платные, либо перегружены лишними функциями, либо не поддерживают смешанные форматы. Goodreads предлагает большую базу данных и социальные функции, но не работает офлайн и слабо кастомизируется. Calibre отлично справляется с электронными книгами, но неудобен для учета бумажных изданий. Libib поддерживает сканирование ISBN, но требует платную подписку и не имеет русского интерфейса. Excel и Google Sheets гибкие и доступные, но требуют полностью ручного ввода и не дают автоматизации.

Library2 предлагает легковесное решение: бесплатное, с автоматическим заполнением данных через Google Books, поддержкой всех форматов и простым консольным интерфейсом, который не требует обучения.

## Как работает

Пользователь вводит ISBN книги или её название. Приложение отправляет запрос к Google Books API и автоматически заполняет все поля: название, автор, жанр, количество страниц. Книга сохраняется в каталог, где её можно редактировать, ставить оценку, отслеживать статус чтения и добавлять рецензии.

Главное преимущество — скорость. Время добавления книги сокращается с 5 минут до 30 секунд. Поиск по каталогу занимает не более 10 секунд. Все книги хранятся в едином интерфейсе независимо от формата: бумажные, EPUB, PDF, аудиокниги.

## Основные функции

- Добавление книг вручную или автоматически через ISBN
- Поиск книг по названию и автору через Google Books API
- Поддержка всех форматов: бумажные, EPUB, PDF, аудиокниги
- Система статусов: Прочитано, В процессе, В планах
- Оценки от 1 до 5 и текстовые рецензии
- Поиск по каталогу: название, автор, жанр, ISBN
- Статистика: книги по статусам, распределение по жанрам, средний рейтинг
- Отслеживание прогресса чтения в страницах
- Список непрочитанных книг

## Архитектура

Приложение построено по модульному принципу и состоит из четырёх основных компонентов:

Модель Book содержит все данные о книге: идентификатор, название, автора, ISBN, жанр, формат, статус чтения, рейтинг, рецензию, количество прочитанных и общих страниц, дату добавления.

Хранилище BookStorage управляет коллекцией книг в памяти: добавление, обновление, удаление, поиск по ключевым словам, фильтрация по статусу, подсчёт статистики по жанрам и среднего рейтинга. Все методы защищены от null-значений.

Сервис GoogleBooksService взаимодействует с Google Books API через HTTP-клиент OkHttp. Поддерживает поиск по ISBN и по названию с автором. Ответ API парсится с помощью Gson, извлекаются название, авторы, категории, количество страниц и ISBN-13.

Консольный интерфейс Main реализует текстовое меню с обработкой пользовательского ввода. Все числовые поля защищены от некорректного ввода, пустые строки корректно обрабатываются.

Стек технологий: Java 17+, Maven, OkHttp для HTTP-запросов, Gson для парсинга JSON, Google Books API как источник данных.

Затраты на внедрение: приложение бесплатно, Google Books API предоставляет 1000 запросов в день бесплатно, для запуска требуется только JRE 17 или выше, интернет нужен только для поиска новых книг.

## Запуск

Требования: JDK 17+, Maven.

Склонируйте репозиторий, перейдите в папку проекта и выполните:

```
mvn compile
mvn exec:java -Dexec.mainClass="org.example.Main"
```

Или откройте проект в IntelliJ IDEA и запустите Main.java.

## Использование

После запуска отображается меню с девятью пунктами. Выберите нужный и следуйте инструкциям.

Пункт 1 — добавление книги вручную с вводом всех полей. Название обязательно, остальные поля можно пропустить.

Пункт 2 — добавление по ISBN. Введите 10 или 13 цифр, приложение найдёт книгу в Google Books и автоматически заполнит данные. Рекомендуется для английских книг.

Пункт 3 — поиск по названию. Работает для книг, которые не находятся по ISBN, в том числе для русских изданий.

Пункт 4 — просмотр всего каталога с общей статистикой по статусам.

Пункт 5 — поиск по библиотеке. Находит книги по совпадению в названии, авторе, жанре или ISBN.

Пункт 6 — редактирование. Можно изменить статус, поставить оценку, записать прогресс чтения, добавить рецензию.

Пункт 7 — удаление книги с подтверждением.

Пункт 8 — статистика: общее количество, распределение по статусам, жанры, средний рейтинг, список непрочитанного.

Пункт 9 — подробная информация о конкретной книге по ID.

Пункт 0 — выход из программы.
