
# Library2 — Система управления личной библиотекой

Консольное Java-приложение для каталогизации, поиска и анализа личной библиотеки с интеграцией Google Books API. Позволяет вести учет книг в едином интерфейсе независимо от формата: бумажные, электронные, аудиокниги.

Понял, вот исправленные разделы в твоём формате — кратко и по делу:

---

## 1. Анализ ситуации и контекста

### Проблема
Учёт книг ведётся вручную: блокноты, Excel, заметки телефона. Бумажные книги — в одном месте, электронные — в другом, аудиокниги не учитываются. Поиск нужной книги занимает 5–15 минут, 25% книг теряются, 15% покупаются повторно.

### Влияние
- Потери времени: до 30% на поиск
- Финансовые потери: дублирование покупок
- Отсутствие аналитики: нельзя оценить прогресс чтения и предпочтения

### Контекст
Человеческий фактор (лень вести учёт) + отсутствие единого инструмента для всех форматов книг.

### Текущий процесс
```
Покупка → Запись в блокнот/Excel/заметки → Данные разрознены → 
Поиск вручную (5-15 мин) → Потеря книги → Повторная покупка
```

---

## 2. Обзор существующих решений

| Решение | Плюсы | Минусы |
|---------|-------|--------|
| Excel / Google Таблицы | Гибкость | Ручной ввод, нет поиска по ISBN |
| Goodreads | Большая база, соцсеть | Перегружен, требует интернета |
| Calibre | Мощный для e-book | Сложный, нет аудиокниг |
| Library2 | ISBN-поиск, все форматы, статистика | Консольный интерфейс |

**Выбор консольного подхода:** минимальные требования, быстрота, работа без интернета для базовых операций.

---

## 3. Концепция решения

### Принцип работы
```
Пользователь
    ↓
Console UI (Main)
    ↓
BookStorage
    ↓
Google Books API
```

### Основные компоненты

| Компонент | Назначение |
|-----------|------------|
| Main | Главное меню, ввод/вывод |
| BookStorage | Бизнес-логика, CRUD, поиск, статистика |
| Book | Модель данных книги |
| GoogleBooksService | Интеграция с Google Books API |

### Преимущества решения
- Автоматическое получение данных о книге по ISBN
- Единый каталог для всех форматов (бумага, EPUB, PDF, аудио)
- Мгновенный поиск по названию, автору, жанру
- Встроенная статистика чтения
- Простая архитектура, минимум зависимостей

## 4. Архитектура решения и детализация внедрения

### Архитектура приложения
```
Main
  ↓
BookStorage
  ↓
Book
  ↓
GoogleBooksService → Google Books API
```

### Алгоритм добавления книги по ISBN
```
Ввод ISBN
   ↓
Валидация (≥10 цифр)
   ↓
Запрос к Google Books API
   ↓
Получение JSON-ответа
   ↓
Извлечение: title, author, genre, pages
   ↓
Создание объекта Book
   ↓
Добавление в BookStorage
```

### Используемые технологии
- Java 17+
- Maven
- OkHttp (HTTP-клиент)
- Gson (парсинг JSON)
- Collections Framework / Stream API
- Google Books API

### Структура данных

**Класс Book** — модель книги:
- id, title, author, isbn, genre
- format (бумажная, EPUB, PDF, аудиокнига)
- status (Прочитано, В процессе, В планах)
- rating (1–5), review
- pagesRead, totalPages, dateAdded

**Класс BookStorage** — управление коллекцией:
- Хранение книг (ArrayList)
- Добавление, редактирование, удаление
- Поиск и фильтрация
- Статистика (по статусам, жанрам, рейтингу)

**Класс Main** — интерфейс пользователя:
- Консольное меню
- Обработка команд
- Взаимодействие с BookStorage и GoogleBooksService

**Класс GoogleBooksService** — работа с API:
- Поиск по ISBN
- Поиск по названию и автору
- Парсинг JSON-ответа

### Технические характеристики

| Параметр | Значение |
|----------|----------|
| Язык | Java 17+ |
| Тип приложения | Консольное |
| Сборка | Maven |
| API | Google Books API |
| Хранение | В памяти (ArrayList) |
| Зависимости | OkHttp, Gson |
